# 유튜브 노래방 - 자막 한글 발음

유튜브 노래의 가사 발음을 한글로 보여 주는 크롬 확장 프로그램입니다. 자막을 켜면 자막 바로 아래에, 자막이 없거나 꺼져 있으면 화면 아래쪽에 지금 부르는 줄의 한글 발음(과 원문)이 나옵니다.

## 설치
1. 이 저장소 페이지에서 **Code → Download ZIP**으로 내려받아 압축을 풉니다. (릴리스 페이지에 zip이 있으면 그걸 받아도 됩니다.)
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 압축을 푼 폴더(`manifest.json`이 들어 있는 폴더) 선택
4. 이미 열려 있던 유튜브 탭은 새로고침합니다.

업데이트할 때는 새로 받은 파일로 폴더를 덮어쓴 뒤 `chrome://extensions`에서 새로고침(↻)을 누르면 됩니다. 크롬 111 이상이 필요합니다.

## 어떤 상황에서 어떻게 동작하나
| 상황 | 동작 |
|---|---|
| 원어 자막(일본어·중국어·영어 등, 자동 생성 포함)을 켰을 때 | 자막 줄을 그대로 한글 발음으로 변환 |
| 한국어 번역 자막만 켰을 때 | 영상 제목으로 공개 가사 DB(LRCLIB)에서 원문 가사를 찾아, 지금 나오는 번역 자막과 맞는 줄의 발음과 원문 표시 |
| 한국어 자막인데 가사를 못 찾았을 때 | 같은 영상의 원어 자막(자동 생성 포함)을 숨은 채로 받아, 지금 시각의 줄을 발음으로 표시 — 노래가 아닌 영상에서도 동작 |
| **자막이 없거나 꺼져 있을 때 (자막 없는 영상 모드)** | 원문 가사의 타임스탬프로 지금 부르는 줄을 화면 아래에 표시. 영상에 자동 자막이 있으면 그걸로 영상↔가사 시간차를 자동으로 맞춤 |
| 한국어 노래 | 섞여 있는 영어 단어만 한글로 바꾸고, 한국어만 있는 줄은 표시하지 않음 |

### 자막 없는 영상 모드
- 가사를 찾으면 바로 동작합니다. 엉뚱한 노래가 뜨지 않도록, 자동 자막으로 싱크가 확인되거나 곡 길이가 영상 길이와 비슷할 때만 표시합니다.
- 싱크가 어긋나면 **Alt+,** (가사 늦게) / **Alt+.** (가사 빠르게) / **Alt+/** (초기화)로 0.5초씩 맞출 수 있고, 영상마다 저장됩니다.
- 팝업의 "가사가 없으면 자동 자막으로 표시"를 켜면, 가사를 못 찾은 영상에서도 자동 자막(음성 인식)의 발음을 보여 줍니다. 노래가 아닌 영상에도 계속 뜨기 때문에 기본값은 꺼져 있습니다.
- 자막 트랙이 하나도 없고 가사 DB에도 없는 노래는 표시할 수 없습니다.

## 가사 찾기
- 제목은 `곡명 [原題 / 가수]`, `(가수 - 原題)`, `「原題」`, `原題 l 가수` 등 여러 형식을 읽고, 커버 가수 이름과 한국어 단어는 검색어에서 뺍니다.
- 제목에 원어 곡명이 없으면 한국어 제목을 일본어로 번역해 다시 찾습니다(예: 사신 → 死神).
- 한국어 제목이 원제와 뜻이 다른 경우(예: '나라는 것' = 僕のこと)는 찾지 못할 수 있습니다.
- 한 번 찾은 가사는 영상별로 저장되어 다음부터 바로 나옵니다.

## 언어별 발음 변환
- **일본어**: 구글 번역의 로마자 표기(한자 읽기 포함) → 한글. 연결이 안 되면 가나만 오프라인으로 변환합니다.
- **중국어**: 병음 → 한글 (중국어 외래어 표기법 기반)
- **영어**: 내장 발음사전(CMU, 약 12만 단어) → 한글. 사전에 없는 단어는 철자 규칙으로 읽습니다.
- **기타(스페인어·러시아어 등)**: 로마자 표기를 소리 나는 대로 읽습니다.

자막이 화면 아래쪽에 붙어 있어서 발음 줄이 영상 밖으로 나갈 경우, 자막 전체를 그만큼 위로 올립니다(자막이 떠 있는 동안 높이를 유지해 줄이 바뀌어도 튀지 않습니다).

## 구조
- `page.js` — 페이지(MAIN world)에서 플레이어 정보(제목·채널·길이·자막 목록)를 읽고, 플레이어가 쓰는 자막 URL을 확보합니다. 자막이 꺼져 있으면 자막 영역을 숨긴 채 잠깐 불러와 URL만 얻고 원래대로 되돌립니다.
- `content.js` — 자막 읽기, 표시 위치, 모드 선택
- `background.js` — 가사 검색(LRCLIB), 번역·로마자(구글 번역), 발음 변환
- `lib/` — 언어별 변환기, 가사 줄 매칭(`match.js`), 자막 트랙·싱크 계산(`track.js`)

## 변경 기록
### 2.0.0
- 자막 없는 영상 모드 추가 (가사 타임스탬프 + 자동 자막 기반 자동 싱크 + 단축키 수동 조정)
- 한국어 자막인데 가사가 없으면 원어 자막(자동 생성 포함) 발음으로 대체 → 노래가 아닌 영상에서도 동작
- 플레이어에서 정확한 영상 정보를 읽어 가사 검색 정확도 향상, 쇼츠·임베드 대응
### 1.3.0
- 줄이 바뀔 때 자막이 깜빡이던 문제, 시작 시 자막을 껐다 켜야 동작하던 문제 수정
- 광고 자막 무시, 반쪽으로 나뉜 짧은 번역 자막도 매칭

## 참고
- 언어 판별과 로마자 표기에는 비공식 구글 번역 엔드포인트(`translate.googleapis.com`)를 씁니다. 결과는 캐시되므로 같은 줄을 다시 요청하지 않습니다.
- 발음은 규칙 기반이라 실제 노래 발음과 조금 다를 수 있습니다.
